დამატებითი ინფორმაცია

<img width="500" height="385" alt="image" src="https://github.com/user-attachments/assets/59351258-2287-4b08-b83e-3dec911a3c4c" />

An example of [Nuskhur](https://ka.wikipedia.org/wiki/ნუსხური) script. The epigraph is written in [Asomtavruli](https://ka.wikipedia.org/wiki/%E1%83%90%E1%83%A1%E1%83%9D%E1%83%9B%E1%83%97%E1%83%90%E1%83%95%E1%83%A0%E1%83%A3%E1%83%9A%E1%83%98), and the main text is in Nuskhur (Grigory the Theologian)

[ნუსხური](https://ka.wikipedia.org/wiki/ნუსხური) დამწერლობის მაგალითი. ეპიგრაფი შესრულებულია [ასომთავრულით](https://ka.wikipedia.org/wiki/ასომთავრული), ხოლო ძირითადი ტექსტი — ნუსხურით (გრიგოლ ღვთისმეტყველი)

Пример [нусхурского](https://ka.wikipedia.org/wiki/ნუსხური) письма. Эпиграф написан на языке [асомтаврули](https://ka.wikipedia.org/wiki/ასომთავრული), а основной текст — на нусхурском (Григорий Богослов).
